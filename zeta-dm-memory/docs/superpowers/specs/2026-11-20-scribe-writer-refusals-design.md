# Keep a writer refusal out of the next message

Approved scope, 20 November 2026.

Scribe currently accepts “I can't write this story.” as a recap and can append it to a player's message. At the point where an automatic writer answer becomes a recap, apply a local check for a clear refusal or an offer to summarize. Recognize the writer speaking about its task, including a refusal followed by template text. Accept a character declining something in the story. This check costs zero additional model calls.

When the writer declines, the player can send their message on time. With no separate operator attachment selected, Zeta receives the player's original text. The reminder remains due. Show one warning, “The writer declined to produce a recap. Your reminder is still due.” A subsequent valid recap can be delivered through the existing interval and acceptance rules.

Apply the same protection to an old automatic preview or cached recap restored from this room. Keep the exact wording of an operator edit or an explicitly queued paragraph, even when it contains the same words as a rejected automatic answer. Preserve outstanding delivery confirmations across refresh.

Verification covers the packed top-page and frame composers, storage restoration, a later valid delivery, and the distinction between a writer refusal and in-story dialogue. The broader evidence and accuracy checker remains a separate item in the session helpers plan.
