# Elsewhere travel demo

Build a self-contained six-page boutique travel showcase in this directory.
Use fictional Elsewhere branding, warm ivory and forest green, large travel
photographs, serif headlines and clear responsive navigation.

## Delivery

- Six public pages: Home, Destinations, Journeys, Our Story, Journal, Contact.
- Shared static HTML layouts generated by Node; CSS and browser JavaScript.
- Destination and journey filtering, itinerary and article dialogs.
- Validated trip enquiries persisted in SQLite by a dependency-free Node 24 server.
- Separate demo dashboard with enquiry status management and sample bookings.
- Clearly identify fictional content, illustrative prices and demo submissions.
- No payment processing, outgoing email, live inventory or booking confirmation.
- Host only the generated public directory; never expose the database or source.
- Validate public navigation, persistence, API access controls, responsive layouts
  and keyboard interactions before delivery.

## Implementation sequence

1. Shared content, visual assets and layouts.
2. Six pages and browser interactions.
3. SQLite store, enquiry API and authenticated demo dashboard.
4. Build, API tests, browser verification and setup documentation.
