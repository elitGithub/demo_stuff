# Asset provenance

All attachment content and fixture illustrations were generated by this repository's `php artisan casefile:build-fixtures` command from `database/seeders/data/fixtures.php`. Run it only with operator approval; it overwrites the configured four files. Names, addresses, companies, amounts and scenarios are fictional. No customer files, stock photography or external image-generation service is used.

| File under database/fixtures/attachments | Generator | Content |
| --- | --- | --- |
| snow-clearing-quote.pdf | App\Support\Pdf\TextPdfWriter | Fictional snow-clearing quote |
| furnace-filter-invoice.pdf | App\Support\Pdf\TextPdfWriter | Fictional furnace-filter invoice |
| kitchen-sink-leak.png | App\Support\Images\IllustrationWriter | Programmatic kitchen-sink illustration |
| thermostat-error.png | App\Support\Images\IllustrationWriter | Programmatic thermostat illustration |

The PNGs are generated illustrations, not documentary photographs, even where a fixture label uses the word photo. `IllustrationWriter` uses PHP GD's built-in bitmap font **5**, with no external TrueType file. The PDF writer refers to standard PDF Helvetica (WinAnsi encoding) and embeds no third-party font file. Fixture attachments remain private and are served through authorized routes.

The interface uses **Instrument Sans**, weights 400/500/600, configured through the existing Laravel Vite Bunny font integration. Its six locally built WOFF/WOFF2 files, font stylesheet and `fonts-manifest.json` are copied into the deployment. No font request is needed at runtime. Packaging changes only generated URL references for the `/casefile` mount, not the font binaries.

[Official upstream](https://github.com/Instrument/instrument-sans) and [official license text](https://raw.githubusercontent.com/Instrument/instrument-sans/master/OFL.txt), obtained 2026-10-17. The complete notice is preserved at `deploy/Instrument-Sans-OFL.txt` and shipped as `casefile/build/Instrument-Sans-OFL.txt`.

Interface icons and layout thumbnails are inline SVG/application markup; no external icon package or stock-image collection is added. Screenshots in `docs/verification` were captured from the isolated local demo and show fictional data. They document selected states, not photographic assets for redistribution. Laravel and vendor libraries retain their respective license notices in production vendor.
