# Upwork portfolio entries

One entry per demo. Images are in `screenshots/`. Check the description length against the portfolio form's limit when pasting. All demos use fictional businesses and data.

## 1. Appointment Booking Website and Studio Workspace

- Role: Full-stack developer (design, build, deployment)
- Link: https://demo-sites.infinityfree.me/studio/
- Images: `booking-website.jpg`, `booking-workspace.jpg`
- Skills: Laravel, PHP, Web Application, Responsive Design, SQLite

Description:

A complete booking system for a salon or any appointment-based business. Clients browse services and team members on a branded website and request visits. Staff get a workspace with an appointment calendar, team availability, client history and preferences, enquiries, memberships, retail stock, invoices and sales reports. Built with Laravel. Try it: open "Studio login" and choose "Explore the demo workspace".

## 2. Restaurant Online Ordering and Kitchen Workspace

- Role: Full-stack developer (design, build, deployment)
- Link: https://resto-chef-demo.infinityfree.me/
- Images: `restaurant-storefront.jpg`, `restaurant-kitchen-overview.png`
- Skills: PHP, Custom PHP, Web Application, Responsive Design, MySQL

Description:

Online ordering for a restaurant or cafe. Customers search the menu, build a cart and choose pickup or delivery. Staff manage dishes, prices and availability, move orders through preparation, ready and delivered, and see daily sales, average order value and popular dishes. Prices are always calculated on the server. Plain PHP with no external dependencies, so it runs on almost any hosting.

## 3. Lightweight CRM with Sales Pipeline and PDF Quotes

- Role: Developer (customization, branding, deployment)
- Link: https://turnkey-demo.is-great.org/
- Images: `crm-dashboard.jpg`, `crm-quote.png`
- Skills: Laravel, Vue.js, CRM Development, PHP, MySQL

Description:

A branded CRM for a small service business, built on the open-source Krayin CRM. Contacts and companies, opportunities in a list or pipeline board, activities and follow-ups, services, and printable PDF quotes. Managers see everything; salespeople see only their own records. Includes mobile layouts and dark mode. Try it: choose "Use demo account" on the sign-in page.

- Role: Full-stack developer (design, build, deployment)

- Images: `home-services-website.png`, `home-services-provider.png`, `home-services-admin.png`

## 5. Travel Agency Website and Enquiry Dashboard

- Role: Full-stack developer (design, build, deployment)
- Link: https://demo-sites.infinityfree.me/travel-agency-demo/
- Images: `travel-website.jpg`, `travel-dashboard.jpg`
- Skills: Node.js, JavaScript, Web Development, Responsive Design, SQLite

Description:

An editorial website for a boutique travel agency: destinations with region filters, journeys with style filters and price sorting, itineraries, a journal and an enquiry form. Enquiries land in a dashboard where the agency tracks each traveller from new to converted, alongside sample bookings. Built with Node.js and its built-in SQLite, with no npm packages.
## 6. Email-to-Case Tracker for Property Managers

- Role: Full-stack developer (design, build, deployment)
- Link: https://demo-sites.infinityfree.me/casefile/
- Images: `casefile-inbox.jpg`, `casefile-case.jpg`
- Skills: Laravel, PHP, Tailwind CSS, Web Application, SQLite

Description:

Turns emails from chosen senders into numbered cases, so nothing gets lost in an inbox. Read the full thread, open attachments, reply, add notes, change status and search the whole history. Each demo visitor gets a private copy to try freely. The demo mailbox is simulated; a live Gmail connection is set up per client. Built with Laravel.
