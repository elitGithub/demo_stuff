# Asset provenance

- public/images/haven-home.svg: original vector illustration created for Haven in this project. No legacy/demo image copied.
- public/images/services.svg and the Blade icon component: original code-native service artwork and line icons created for Haven.
- Professional avatars use fictional business initials and generated color assignments.
- Instrument Sans is bundled locally by the Laravel Vite font integration; its upstream license accompanies the font distribution. System fonts remain the fallback.
- Request photo fixtures are generated locally for fictional jobs; no customer photographs are used.

## Private request image

The original database/demo/request-kitchen.png geometric kitchen illustration is generated with the included standalone GD script. It represents a fictional kitchen, is not a property photo and contains no copied legacy imagery. The seeder stores a private copy via the same photo storage service used by request uploads.
